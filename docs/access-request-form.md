# Sample Access Request Form

## Request Details

| Field | Example |
|---|---|
| Requestor | Alice HR |
| Department | HR |
| Requested Access | `HR_ReadOnly` |
| Business Reason | Needs access to HR resources for job duties |
| Approval Required | Manager approval |
| Risk Level | Low |
| Review Date | Monthly access review |

## Access Approval Notes

Access should be granted only when there is a valid business reason. Users should receive the lowest level of access needed to perform their job duties.

## Example Approval

Alice HR was approved for the `HR_ReadOnly` role because the role matches her department and does not include administrative privileges.
